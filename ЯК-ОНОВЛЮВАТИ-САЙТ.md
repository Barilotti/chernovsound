# Як оновлювати сайт CHERNOVsound

Сайт наповнюється через **адмінпанель** у браузері, код чіпати не потрібно. Адмінпанель працює на безкоштовному сервісі **Pages CMS**, а сам сайт безкоштовно розміщується на **GitHub Pages**. Ви натискаєте «Зберегти» в адмінці, і за 1–2 хвилини зміни з'являються на сайті.

## Запуск (один раз)

1. **Створіть акаунт на GitHub:** https://github.com/signup (безкоштовно).
2. **Створіть порожній репозиторій** (це «папка» для сайту): https://github.com/new
   - Repository name: `chernovsound`
   - Оберіть **Public** (для безкоштовного GitHub Pages).
   - Більше нічого не змінюйте, натисніть **Create repository**.
3. **Підключіть GitHub до Claude** і напишіть мені назву репозиторію. Я сам завантажу туди сайт.
4. **Увімкніть сайт:** у репозиторії відкрийте **Settings → Pages**, у розділі «Branch» оберіть `main` і папку `/ (root)`, натисніть **Save**. За пару хвилин сайт з'явиться за адресою `https://ваш-логін.github.io/chernovsound/`.
5. **Відкрийте адмінпанель:** https://app.pagescms.org → **Sign in with GitHub** → дозвольте доступ до репозиторію `chernovsound` → оберіть його. Посилання на адмінку збережіть у закладки.

## Що є в адмінпанелі

| Розділ | Що там |
|---|---|
| **Портфоліо** | Роботи: назва, послуга, аудіо/відео/YouTube, обкладинка, опис |
| **Відгуки** | Ім'я, текст, оцінка, фото або скриншот відгуку |
| **Про мене** | Ваше фото, розповідь, цифри (досвід, проєкти), список проєктів |
| **Контакти та соцмережі** | Пошта, Telegram, YouTube, Instagram тощо (іконки внизу сайту) |

### Додати роботу

1. **Портфоліо** → у списку «Роботи» натисніть **Add an entry** (додати).
2. Заповніть назву, оберіть послугу і тип:
   - **Аудіофайл:** завантажте mp3 у поле «Аудіо». Якщо додасте ще файл «До обробки», на сайті з'явиться перемикач **До / Після**.
   - **YouTube:** вставте посилання на відео.
   - **Відео з Google Drive:** завантажте відео на Google Drive → «Поділитися» → «Усі, хто має посилання» → «Копіювати посилання» і вставте його в поле «Посилання на Google Drive». Підходить для аніме й серіалів, які YouTube блокує через авторські права. Після завантаження Drive кілька хвилин обробляє відео, перш ніж воно почне відтворюватися.
   - **Відеофайл:** невеликі mp4 (до ~50 МБ). Великі краще викладати на YouTube.
3. Перетягніть нову роботу нагору списку, щоб вона була першою.
4. Натисніть **Save**.

### Додати відгук

**Відгуки** → **Add an entry** → ім'я, текст, оцінка → **Save**. Якщо відгук прийшов у Telegram або на біржі, можна просто завантажити скриншот.

### Прибрати приклади

Зараз на сайті є приклади з позначкою «Приклад». Коли додасте свої роботи, видаліть приклади (кнопка з кошиком) або вимкніть у них «Позначка «Приклад»». У блоці «Про мене» вимкніть позначку, коли заповните його.

## Що міняю я, а не адмінка

Тексти послуг, «Чому я», заголовки та переклади зашиті в сам сайт. Якщо захочете їх змінити, просто напишіть мені, що саме.

## Власний домен (за бажанням)

Якщо купите домен (наприклад, chernovsound.com), його можна підключити в **Settings → Pages → Custom domain**. Напишіть мені, і я оновлю адресу сайту в налаштуваннях для Google.
